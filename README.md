# Healthcare Chatbot with LangChain Guardrails

A healthcare chatbot built using **LangChain, LangGraph, and OpenAI GPT-4o**.

- Implements middleware-based guardrails for healthcare conversations.
- Blocks harmful and off-topic requests.
- Protects sensitive information using PII redaction and masking.
- Implements human-in-the-loop approval for appointment booking.
- Adds medical disclaimers to chatbot responses.
- Demonstrates symptom information, medication information, and appointment-booking tools.

**Setup:** Install the required dependencies and configure your `OPENAI_API_KEY` before running the notebook.
